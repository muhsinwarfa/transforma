Status badges

Transforma extension

The shared review lifecycle, used everywhere a review appears: Draft → In review → Awaiting acknowledgement → Locked, plus Flagged — and a neutral Unavailable for unknown/edge statuses. Built from Hogaan's semantic tokens — cyan for the subject's turn (Awaiting acknowledgement), neutral for Locked, the warning token for Flagged.

Button hierarchy

From Hogaan

Hogaan's button system: primary (filled blue, blue glow, hover → deeper), secondary, destructive, ghost, plus the outline variant. Active press scales to 0.985; disabled drops to navy-8% fill.

Form fields

From Hogaan

Text, textarea and select built on Hogaan's recessed --surface-field. States: default, focus (blue ring), filled, error, disabled. Every control is labelled and meets a 44px minimum height.
